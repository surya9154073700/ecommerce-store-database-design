# E-Commerce Store Database Design

## Overview
This project demonstrates the design and implementation of a relational database for an e-commerce platform using SQL. The database is structured to manage customers, products, categories, orders, payments, and inventory while ensuring data integrity through normalization.

## Features
- Relational database design
- Normalized database schema
- Primary and Foreign Key relationships
- Customer Management
- Product Management
- Order Processing
- Payment Records
- SQL queries for reporting and analysis

## Technologies Used
- SQL
- MySQL
